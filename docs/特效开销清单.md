# 特效开销清单

实测，不是估计。机器：Apple M5 Max（Metal），分辨率 1920x1080，画质档 High，抗锯齿 STP。
方法：`tools/fxcost.sh` 在 Mac 包里跑 `EffectCostBench`：四个固定机位，每个先测基线，再每次只关一项、测完恢复；关垂直同步，用 FrameTimingManager 的 GPU 帧时间（1.5 秒，去掉最慢 10%）。开销 = 基线 − 关掉后。
测量噪声约 ±0.2 ms（同一项在不同机位会出现小的负值，例如室内看不到草时关草反而 −0.8 ms，那是噪声和异步调度，不是真开销）；绝对值小于 0.2 ms 的项视为测不出差别。

| 效果 | 草地白天 | 深林 | 湖岸夜晚 | 木屋室内 |
|---|---|---|---|---|
| 基线 GPU 帧时间 | 6.55 ms | 7.81 ms | 8.59 ms | 1.79 ms |
| 草地（GPU 草） | +0.70 ms | +1.08 ms | +1.41 ms | -0.78 ms |
| SSAO 环境光遮蔽 | +2.79 ms | +3.19 ms | +3.79 ms | +1.27 ms |
| 高度雾 | +0.07 ms | +0.07 ms | -0.00 ms | -0.19 ms |
| 泛光 Bloom | -0.06 ms | -0.17 ms | -0.11 ms | +0.10 ms |
| 主光阴影 | -0.04 ms | -0.01 ms | -0.02 ms | -0.10 ms |
| 点光源（全部附加光） | -0.01 ms | +0.00 ms | -0.01 ms | +0.05 ms |
| 粒子（全部粒子系统） | -0.05 ms | -0.06 ms | -0.04 ms | -0.06 ms |
| 水面（含反射） | -0.18 ms | +0.05 ms | +0.06 ms | +0.19 ms |
| 抗锯齿 TAA（相对关） | +0.03 ms | +0.03 ms | +0.00 ms | +0.03 ms |
| 抗锯齿 STP（相对关） | +0.17 ms | +0.02 ms | +0.10 ms | +0.04 ms |

## 结论

- **SSAO 环境光遮蔽**：2.79 / 3.19 / 3.79 / 1.27 ms，是主要开销。
- **草地（GPU 草）**：0.70 / 1.08 / 1.41 / -0.78 ms，是主要开销。
- 其余各项在这台机器上都低于测量噪声。低、中档关 SSAO、降草地距离（docs/画质分级.md，先定后测）与这张表的结论一致。

1070 Ti / 5060 Ti 上的数据：未测（Windows 包打好后用同一脚本采集）。
