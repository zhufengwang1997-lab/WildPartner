# 自动续跑任务队列

主会话被额度暂停时，由定时任务按顺序接着做。做完一项就把 `[ ]` 改成 `[x]`，并在后面写一句结果和提交号。

规则：一次只做一项；每项限时 45 分钟，做不完就写明卡在哪，然后做下一项。

- [ ] 1. README.md（PRD 7.3）：项目简介、截图、如何运行、操作说明、架构图（文字或 mermaid）、功能状态总表（来自 docs/STATUS.md）、实测数据摘要及出处、AI 辅助开发说明（Claude Code 写代码和文档，Tripo 生成模型）。所有数字必须能在仓库里找到出处。
- [ ] 2. 挂机测试里 GC 约每秒一次：找出每帧分配内存的代码（Profiler 或代码审查），能简单修就修，重跑 `tools/soak.sh 600 mac-<日期>`，更新挂机报告。
- [ ] 3. 爬墙时镜头被附近的树挡住（1123c-B4 遗留）：攀爬时让镜头避开树（相机碰撞或拉近），冒烟截图确认。
- [ ] 4. 锦鲤水瓶特写镜头偏远（1123e-2 遗留）：调 `Core/Showcase.cs` 的机位，让瓶子在图里明显，重拍 `tools/showcase_1123e.sh` 相关截图。
- [ ] 5. 演示备份录屏：按 `docs/演示流程.md` 用 Mac 包录几段 GIF/视频（复用 tools/make_gif.py 的做法），放 `docs/screenshots/demo/`。
