# TC-10 挂机测试：Apple M5 Max（Metal）

数据：`../bench_results/soak-mac-20261123/soak.csv`。1920x1080，画质档 High，超分 STP，时长 600 s（说明书要求 30 分钟，最终指令压缩为 10 分钟）。
女巫自动随机走跑，每 2 分钟随机切换晴雨，昼夜照常流动。帧率按游戏默认的垂直同步。

| 项目 | 结果 |
|---|---|
| 跑完全程不崩溃 | 是（599 s，player exit code 0） |
| 帧率：第 1 分钟（30–90 s）→ 最后 1 分钟 | 118.0 → 117.9 FPS（-0.0%） |
| 最慢一帧（全程） | 25.0 ms |
| 内存：第 1 分钟 → 最后 1 分钟 | 171 → 171 MB（-0 MB） |
| GC 次数（全程） | 512 |

> 11-23 晚修了 5 处每帧内存分配后重跑：GC 512 → 69 次，见 `挂机测试-mac-20261123-gcfix.md`。

**结论**：通过（标准：跑完不崩溃，最后 1 分钟帧率不低于第 1 分钟的 90%）。
