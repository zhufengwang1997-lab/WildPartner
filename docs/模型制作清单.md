# 模型制作清单（给用户，在 Tripo 里做）

做好后导出 **GLB**，按下表"文件名"命名，放进 `Assets/_Game/Models/_Inbox/`。放一个，Claude Code 就替换一个。

## 统一风格（每条提示词末尾都加上这一句）
> stylized hand-painted 3D game asset, soft rounded shapes, warm storybook colors, Ghibli-inspired, clean silhouette, single object, plain background, no ground plane

最好的做法：先用提示词生成一张图，觉得风格对了，再"图片转 3D"。所有模型保持同一种画风比单个模型精细更重要。

## 你已经做好的（不用再做）
主角女巫、月影兔、月影蝶、白色神鹿；木屋室内：木门、木窗、壁灯、木桌、木凳、木床、壁炉。
木屋室内的梁柱、地板、墙面由 Claude Code 用 Blender 搭建（规则形状，不需要 Tripo）。

## 不用你做的
- 草、花、蘑菇：由 Claude Code 用面片做（数量大，必须轻量）
- 骨骼和动作：全部由 Claude Code 通过 Blender 完成

## 生物模型的姿势要求（方便后面绑骨骼）
- 四足动物：四条腿分开站立，不要趴着或腿并在一起
- 猫：四腿分开站立，尾巴不要贴着身体
- 蝴蝶：翅膀完全张开、平展
- 人形：手臂张开（A 字形或 T 字形）最好
