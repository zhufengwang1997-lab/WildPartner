# 选择器与能力探测

## 一句话
开机时自动判断"这台电脑能用哪种超分、用哪一档"，玩家也可以手动改，并且记住。

## 为什么需要它
像导航软件自动选路线：它先知道哪些路通（能力探测），再按规则挑最好的一条（选择器），你不满意还能手动改。不同显卡支持的超分不一样：DLSS 只有 RTX 卡能用，MetalFX 只有苹果芯片能用。

## 怎么做的
1. **能力探测（GpuCaps，项目二的包）**：读出显卡型号、驱动、API 和各项特性。本次升到 schema 2，新增三项：`dlss`、`fsr`、`metalfx`。
   - 判断依据是硬件和系统，比如 Windows 加 RTX 显卡，或者 macOS 加 Metal 加苹果 GPU。
   - 后端真正启用前，还要再问一次自己的 SDK。
2. **选择顺序**：DLSS → MetalFX → STP → FSR 1 → 渲染缩放，取第一个支持的。
   - STP 排在 FSR 前，因为它是时间性的，能用多帧补细节。
3. **档位映射**：画质档低 → 性能（渲染 50%），中 → 平衡（59%），高 / 极高 → 质量（67%）。
4. **优先级**：启动参数（`-upscaler=` / `-quality=`）> 玩家在设置里的选择（存盘）> 自动。选择结果和理由写进日志，F3 面板上也显示"选择依据"。

## 数据
- EditMode 测试覆盖了几项规则：
  - 选择顺序；
  - 档位映射；
  - 玩家选择和启动参数的优先级；
  - 启动参数指定了不可用的后端（如 DLSS）时会被忽略。
- M5 Max 的能力报告：`docs/caps/caps_AppleM5Max_Metal.json`。

## 面试官可能追问
1. **为什么不在能力探测里直接调 NVIDIA 的接口？**
   - 能力探测是跨项目复用的包，不能依赖厂商 SDK（约束 C3）。所以分两层：包只看硬件，后端自己再确认。
2. **自动选错了怎么办？**
   - 后端初始化失败会退回下一个（设计要求，原生后端实现时落实）。玩家也可以在设置里手动改，并且会存盘。
3. **为什么质量档是 67%？**
   - 这是业界常用的比例：质量 1.5 倍、平衡 1.7 倍、性能 2 倍。
4. **低档为什么默认 TAA 而不是 STP？**
   - STP 比 TAA 多做一步重建。在 M5 Max 1080p 四个机位上，STP 比 TAA 多 0 到 0.14 ms（相对值），在测量噪声（约 ±0.2 ms）以内，所以这是按设计取舍定的：低档机器先省掉这一步，不是实测出的大差距。
5. **怎么验证选择器在三台机器上的结果？**
   - 日志里有 `[Upscaler] 选择：…` 一行。Windows 测试包会把日志拷回来。

## 坦白清单
- DLSS 和 MetalFX 的字段只做了硬件判断，没有调用 SDK 查询（`IsFeatureAvailable`、`supportsDevice`）。说明书要求要查，这一点未达到。
