# 三分钟总览

## 一句话
《荒原伙伴》是一款收集小动物伙伴的 3D 探索游戏。技术部分做的是一套能复用的超分中间件：统一接口、自动选择、输入准备、自动评估。另外把项目二的画质分级、能力探测、性能采集三个包直接复用过来。

## 讲法（约 3 分钟）
1. **游戏（30 秒）**：女巫在山谷里找五种伙伴（猫、月兔、白鹿、月影蝶、锦鲤），有昼夜、天气、钓鱼、爬塔。模型用 Tripo 生成，骨骼和动作在 Blender 里自己做。
2. **为什么做超分（30 秒）**：同样的显卡想要更高帧率，就先用低分辨率渲染，再"聪明地"放大。难点在于各家方案接口不同：DLSS、FSR、MetalFX、STP。
3. **我做了什么（1 分钟）**：
   - 统一接口 `IUpscaler`，三个后端：STP、FSR 1、渲染缩放。加后端不改游戏代码。→ 讲稿 02
   - 选择器：按显卡能力自动挑后端和档位；能力探测是项目二的包，升了一版。→ 讲稿 04
   - 输入准备 IN-01 ~ 08：运动向量（包括风吹草动）、Reactive Mask、镜头切换清历史。F3 面板能直接看。→ 讲稿 03
   - 先把原生分辨率的时间性抗锯齿打通，再做降分辨率。→ 讲稿 01
4. **结果（40 秒）**：M5 Max 2560×1440 的自动评估，6 个场景 × 15 种配置。→ 讲稿 05
   - STP 画质最好，6 个场景都赢。
   - 质量档帧率：渲染缩放 +42%，STP +34%，FSR 1 +33%。说明书要求 +40%，只有渲染缩放达标。原因是这台机器上游戏接近 CPU 瓶颈。
5. **没做成的，直接说（20 秒）**：
   - GRD 在 Mac 上打开后，交给它画的物体全都不显示（连 URP 自带材质的方块也一样），根因没找到，默认关闭；Windows 上会再试。→ 讲稿 06
   - DLSS、MetalFX、FSR 2/3、光追、VRS、崩溃诊断只有设计文档。
   - Windows 两台机器的结果以 24 日测试为准。

## 面试官可能追问
1. **最难的问题是什么？** 两次"画面坏了但测试通过"：打包后 STP 被剥离导致黑屏；GRD 打开后树消失。我从中学到，自动测试必须检查画面本身，不能只看逻辑。
2. **怎么保证数据可信？** 每个数字都能追到仓库里的 CSV 和截图，写明设备、分辨率、日期。评估里还量了噪声底。
3. **AI 用在哪里？** 代码和文档由 Claude Code 协助完成；模型用 Tripo 生成。所有测试数据都是真实运行得出的。
4. **项目二和这个的关系？** 三个包按 Git 标签引用，没有复制代码，这次还给其中两个升了版本。→ 讲稿 07
5. **如果再给一周？** 修 GRD；接 DLSS（在 5060 Ti 上）和 FSR 2/3 原生插件，让 Reactive Mask 真正派上用场；用 Development 包测超分 Pass 本身的耗时。
