# 演示流程（面试现场，约 8 分钟）

准备：Mac 包 `Builds/Mac/WildPartner.app`，窗口 2560×1440 或全屏。开场前把设置里的超分方案和档位都设为"自动"，按 F3 打开调试面板。

1. **开场（1 分钟）**：主菜单 → 新游戏，女巫在木屋醒来。走出木屋，第一眼看木屋前院和远山。
2. **抗锯齿对比（1.5 分钟）**：站到草地上，镜头对着草和树。F3 面板里依次点"关 / TAA / STP"。
   - 关：草叶边缘和树枝闪烁、锯齿明显。
   - TAA：边缘平滑，略软（有 0.4 锐化）。
   - STP：边缘平滑且细节更多。
   - 面板上同时显示帧时间。
3. **超分切换（2 分钟）**：F3 面板切换超分方案（STP / FSR 1 / 渲染缩放）和档位（质量 / 平衡 / 性能）。
   - 渲染分辨率一行随之变化。
   - 界面文字始终清晰（IN-07：界面在放大之后按显示分辨率绘制）。
   - 讲"同一个接口，三个后端，游戏层不改代码"。
4. **输入可视化（1 分钟）**：输入视图切到"运动向量"，跑动，人物、猫、摆动的草都有颜色。切到"Reactive Mask"，下雨时雨丝和瀑布水雾是亮的（已生成，当前后端未消费）。
5. **镜头切换和历史重置（1 分钟，IN-08）**：走到木屋门口按 E 进屋。进出门是一次镜头瞬移，触发 `CameraCut` → `ResetHistory()`，预期画面不会留下上一位置的残影（SC-05 场景的截图验证见超分评估报告；肉眼对比尚未做）。
6. **画质档位（30 秒）**：设置菜单切"画质档位"低 / 中 / 高 / 极高，草的距离、树的细节、SSAO、湖面反射随之变化（`docs/画质分级.md`）。
7. **数据（1 分钟）**：打开 `docs/超分评估报告-mac-*.md` 和 `docs/特效开销清单.md`，讲画质–帧率散点图和推荐默认配置。

已知风险：Windows 两台机器上的表现以 24 日测试结果为准；演示用 Mac。
