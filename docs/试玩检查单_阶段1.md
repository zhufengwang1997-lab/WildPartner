# 试玩检查单 · 阶段 1（约 10 分钟）

打开 `Builds/Mac/WildPartner.app`（或在 Unity 里打开 `Assets/_Game/Scenes/World.unity` 按 Play）。

| # | 你做什么 | 应该看到什么 |
|---|---|---|
| 1 | 启动游戏 | 主菜单"荒原伙伴"，背景是缓慢环绕的世界俯瞰；按钮：新游戏 / 设置 / 退出（有存档时多一个"继续"） |
| 2 | 点"新游戏" | 女巫站在悬崖木屋前（东南高地），屏幕下方依次出现操作提示；左上角显示目标"收集伙伴 0/5"，右上角显示时钟和天气 |
| 3 | WASD 走、Shift 跑、Ctrl 潜行、鼠标转视角、滚轮拉远近 | 角色移动有上下起伏；镜头不会穿进地形/岩石 |
| 4 | 按 Tab | 图鉴：5 个格子，未捕捉的显示剪影和线索文字（在哪、什么时间/天气出现） |
| 5 | 沿木屋坡道下山去西边的石阵草甸（白天） | 找到月影兔；靠近后出现"按住 E 捕捉"和进度条；走太快它会警觉（黄色警觉条），潜行靠近更容易 |
| 6 | 按住 E 直到进度满 | 提示"捕捉成功：月影兔！（1/5）"，兔子变为跟随你的伙伴 |
| 7 | 按 Esc → 返回主菜单 → 继续 | 回到原位置，已捕捉的伙伴仍在身边，时间与进度保留 |
| 8 | 等待或继续游玩到夜晚（一天 = 8 分钟） | 天空变暗、出现星星，篝火和路灯亮起；月影蝶只在夜间湖边出现 |
| 9 | 下雨时去河边木桥附近 | 雨粒子与雨声；赤墨锦鲤只在雨天出现（不下雨超过 3 分钟必定会下雨） |
| 10 | 收集全部 5 种后回到木屋篝火旁 | 伙伴围坐篝火，出现结局画面和用时；可返回主菜单 |
| 11 | 设置菜单 | 画质档位（低/中/高/极高）、鼠标灵敏度、反转 Y、音量；改动立即生效，重启后保留 |

快速验证捕捉流程可用的生物位置：月影兔（石阵东南草甸，白天）、白色神鹿（北部秋色林）、林鸮（西部瞭望塔附近）、月影蝶（湖边，夜晚）、赤墨锦鲤（木桥附近河里，雨天）。
