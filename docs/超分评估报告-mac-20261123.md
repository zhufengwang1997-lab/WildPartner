时间稳定性只在静止场景（SC-02 草地、SC-06 远山）测：60 帧相邻帧亮度差的平均值，越大越闪。
帧时间：关垂直同步、不限帧率时的实际每帧耗时，FPS 由它算出。GPU ms 来自 FrameTimingManager，在 Metal 上包含多帧并行的排队时间（约为帧时间的 2 倍），只能用来比较配置之间的相对高低。
超分 Pass ms、显存：来自 URP 性能采样器和 Gfx Used Memory 计数器，发布版不提供时显示「—」。

**噪声底**：同一参考配置拍两次（ref2 对 ref），FLIP = 0.0740。这是测试本身控制不住的差异（鱼群、小动物等按真实时间动的东西）。其余配置之间 FLIP 最大差 0.0615。所有配置都带着同一份噪声，所以单个差值要谨慎看；更可靠的依据是下面逐场景表里的排序是否在 6 个场景中一致。

## 默认配置建议

**STP_Balanced**：FLIP 0.1168 不超过最佳原生抗锯齿（0.1069）的 110%，其中帧率最高（173 FPS）。

规则：在 FLIP 不超过最佳原生抗锯齿（native_taa / native_stp）110% 的配置里取帧率最高的。native_off（不抗锯齿）不参加：参考图是不带时间滤波的超采样，FLIP 天然偏向它，但它的闪烁（时间稳定性一列）约是 STP 的 2 倍。这条规则只看画质和帧率，游戏里的自动档位仍按说明书映射（高档 → 质量档），推荐结果供演示前手动调整参考。
