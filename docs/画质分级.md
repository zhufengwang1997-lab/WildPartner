# 画质分级（四档）

档位由 `com.zfw.qualitytiers` 选（自动 / 设置菜单 / 启动参数 `-tier=`），GpuCaps 兼容表可以封顶。每档 = 一份 URP 资源 + 通用参数 + 本游戏扩展 `WildPartnerTier`。

| 项目 | 低 | 中 | 高 | 极高 | 在哪 |
|---|---|---|---|---|---|
| 主光阴影贴图 | 1024 | 2048 | 4096 | 4096 | URP 资源 |
| 阴影距离 / 级联 | 60 m / 1 | 90 m / 2 | 110 m / 4 | 160 m / 4 | URP 资源 |
| 粒子密度（雨等） | 40% | 70% | 100% | 100% | 通用参数 |
| 泛光 | 关 | 3 级 | 5 级 | 6 级 | 通用参数 |
| 草地距离与密度 | 0.55 | 0.8 | 1.0 | 1.25 | `WildPartnerTier` |
| LOD 偏移（树保持高模的距离） | 0.7 | 1.0 | 1.3 | 1.8 | `WildPartnerTier` |
| SSAO | 关 | 关 | 开 | 开 | `WildPartnerTier` |
| 湖面反射探针 | 64 | 64 | 128 | 256 | `WildPartnerTier` |
| 默认抗锯齿 | TAA | STP | STP | STP | `WildPartnerTier`（玩家选过则以玩家为准） |
| 渲染比例 / 超分 | 待超分阶段定 | | | | |

验证：冒烟测试逐档切换，检查以上游戏参数都生效。各项的实际开销见 `docs/特效开销清单.md`。1070 Ti 上各档帧时间：未测。
